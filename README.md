# Customer Support Response Time Analysis

This repository contains a professional Seaborn visualization analyzing **customer support response times** across different channels (Email, Chat, Phone). The visualization was created as part of a data visualization assignment.

## Contents

- **chart.py**: Python script that generates the violin plot using Seaborn.
- **chart.png**: Generated visualization image (512x512 pixels).
- **README.md**: This file.

## Overview

- The script generates **synthetic data** representing customer support response times.
- A **violin plot** is created to show the distribution of response times for each support channel.
- Professional styling and labeling are applied to make the chart presentation-ready.
